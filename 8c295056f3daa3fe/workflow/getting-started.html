Getting started

The quickest start is workflow init: it writes a notebook with a small model, benchmarks before and after training, and saving, that runs as-is (CLI). This page explains the pieces.

A model is a stack of layers. Each layer receives the previous layer's output, so the only numbers you write are the ones you decide: output channels, kernel sizes, strides, padding.

import workflow as wf

model = wf.stack(
    wf.input(channels=3, height=640, width=640),

    wf.Conv2D(32, kernel_size=3, stride=2, padding="same"),
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.Bottleneck(),
)
model.summary()
  • The first number is the output channels. In wf.Conv2D(32, kernel_size=3), 32 channels come out; the input channels are worked out from the previous layer.
  • The first line says what goes in. wf.input(channels=3, height=640, width=640) builds the model for RGB pictures of that size and checks every layer before anything runs (3×640×640 if you leave it out).
  • Padding is a word. padding="same" keeps the size (with stride=2 it halves it); padding="valid" adds none, so the picture shrinks a little.
  • Bias is automatic. A convolution right before BatchNorm2D has none; any other has one.

A detector

One layer per line, top to bottom, exactly as the picture flows through them:

model = wf.stack(
    wf.input(channels=3, height=256, width=256),

    # stem: 256 → 128
    wf.Conv2D(16, kernel_size=3, stride=2, padding="same"),
    wf.BatchNorm2D(),
    wf.SiLU(),

    # 128 → 64
    wf.Conv2D(32, kernel_size=3, stride=2, padding="same"),
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.CSP(n=1),

    # 64 → 32: good for small objects
    wf.Conv2D(64, kernel_size=3, stride=2, padding="same"),
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.CSP(n=2),
    wf.feature("p3"),

    # 32 → 16: medium objects
    wf.Conv2D(128, kernel_size=3, stride=2, padding="same"),
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.CSP(n=2),
    wf.feature("p4"),

    # 16 → 8: large objects
    wf.Conv2D(256, kernel_size=3, stride=2, padding="same"),
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.SPPF(kernel_size=5),
    wf.feature("p5"),

    # neck and head
    wf.FPN("p3", "p4", "p5", channels=64),
    wf.PAN(channels=64),
    wf.head(classes=3),
)

Train, evaluate, use

import felix as fx
data = fx.load("shapes.felix")                       # Felix gives train / val / test splits

model.train(data.train, validation=data.val, epochs=50)
wf.eval(model, dataset=data.test)
model.save("detector.nbm")

model = wf.load("detector.nbm")
run = wf.inference("photo.jpg", model, "results/")   # → results/original/, results/annotated/, results/predictions.json
first = run.images[0]
print(first.xyxy, first.classes, first.confidences)
