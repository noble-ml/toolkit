Layers

Every layer infers its input channels. Shapes below are (channels, height, width); *pair* means an int or an (height, width) tuple.

Padding

Every layer with a window (convolutions and pooling) takes padding="same" or padding="valid":

padding=MeaningOutput size (per axis)
"valid" (default)no padding: the window only visits real pixels, so the picture shrinks⌊(size − dilation·(kernel − 1) − 1) / stride⌋ + 1
"same"pads just enough to keep the size; with a stride, the size is divided by the stride and rounded up⌈size / stride⌉

How "same" pads: with an odd kernel (3, 5, 7, ...) it adds (kernel − 1) / 2 pixels on every side, exactly like the classic "padding 1 for a 3×3"; with an even kernel the extra pixel goes on the bottom and right. Padding is worked out for each input size, so a model built at 640×640 also runs at 416×416. Numbers (padding=1) are not accepted: the error tells you which name to use.

Convolutions

The first argument is always out_channels: how many channels come *out* (how many different patterns the layer looks for). Input channels are never written: Workflow works them out from the previous layer.

Conv2DConv2D(out_channels, kernel_size=3, stride=1, padding="valid")out_channelsstandard convolution
DilatedConv2DDilatedConv2D(out_channels, kernel_size=3, dilation=2, stride=1, padding="valid")out_channelstaps spread dilation pixels apart; "same" keeps the size
DepthwiseConv2DDepthwiseConv2D(kernel_size=3, stride=1, padding="valid")same as inputone filter per channel
PointwiseConv2DPointwiseConv2D(out_channels)out_channels1×1 convolution: kernel 1, stride 1, no padding (fixed)
SeparableConv2DSeparableConv2D(out_channels, kernel_size=3, stride=1, padding="valid")out_channelsdepthwise then pointwise
TransposeConv2DTransposeConv2D(out_channels, kernel_size=2, stride=2, padding="valid")out_channelsupsampling convolution: "valid" gives (size − 1)·stride + kernel, "same" gives size·stride (needs kernel_size ≥ stride)

Requirements: out_channels ≥ 1; kernel_size, stride, dilation ≥ 1 (an int, or (height, width)). If the kernel does not fit the input (with "valid"), the error says how big each one is and suggests "same". Weights are initialised uniformly in ±1/√fan_in.

Pooling and resizing

Pooling slides a window over the picture and keeps one number per window. No weights are learned.

LayerSignatureKeeps
MaxPool2DMaxPool2D(kernel_size=2, stride=None, padding="valid")the largest value in each window
MinPool2DMinPool2D(kernel_size=2, stride=None, padding="valid")the smallest value in each window
AvgPool2DAvgPool2D(kernel_size=2, stride=None, padding="valid")the average of each window
UpsampleUpsample(scale=2)(not a pool) makes the picture scale times bigger by copying pixels (nearest neighbour)
  • stride defaults to kernel_size, so MaxPool2D(2) halves the picture.
  • padding="same" with stride=1 keeps the size: MaxPool2D(kernel_size=5, stride=1, padding="same") is the pooling used inside SPPF.
  • Padded pixels never win a max or a min. In an average they count as zero.
