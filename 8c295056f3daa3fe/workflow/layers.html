Layers

Every layer infers its input channels. Shapes below are (channels, height, width); *pair* means an int or an (height, width) tuple.

Padding

Padding is always a number of pixels, never "same" / "valid" (those raise an error that suggests the number):

padding=Meaning
0none (the old "valid")
1, 2, ...that many pixels on every side
(ph, pw)ph top and bottom, pw left and right
(top, bottom, left, right)asymmetric

Output size along one axis: ⌊(size + pad_before + pad_after − dilation·(kernel − 1) − 1) / stride⌋ + 1. For stride 1, padding = kernel_size // 2 keeps the size (odd kernels).

Convolutions

DepthwiseConv2DDepthwiseConv2D(kernel_size=3, stride=1, padding=0)same as inputone filter per channel
PointwiseConv2DPointwiseConv2D(filters)filters1×1 convolution, keeps the resolution
SeparableConv2DSeparableConv2D(filters, kernel_size=3, stride=1, padding=0)filtersdepthwise then pointwise
TransposeConv2DTransposeConv2D(filters, kernel_size=2, stride=2, padding=0)filtersupsampling convolution; output (size − 1)·stride − 2·padding + kernel. Symmetric padding only

Requirements: filters ≥ 1; kernel_size, stride, dilation pairs ≥ 1; padding ≥ 0. If the kernel does not fit the (padded) input the error says how big each one is. Weights are initialised uniformly in ±1/√fan_in.
