Changes

0.4.1

  • Upgrading Workflow while a notebook kernel (or any Python session) still has the old version loaded now stops with a plain "restart the session" message, instead of failing part-way with errors such as 'Batches' object has no attribute 'iterate'.

0.4.0

  • CPU training 3.3–4× faster (the workflow init model on a 2-core 2012 laptop: 3.5 → 11.7 images/s at 320 px, 0.76 → 3.0 at 640 px), with the same results:
  • convolutions use a packed, register-blocked matrix multiply (6×16 micro-kernel; AVX, AVX2+FMA or NEON) that reads the picture directly (no im2col copy), forward, weight gradient and stride-1 input gradient;
  • BatchNorm + activation run as one vectorised pass and the BatchNorm output is no longer stored;
  • vectorised exp / sigmoid / SiLU; multi-threaded upsample and pooling backward; vectorised max pooling.
  • Less memory: backward frees what each layer kept as soon as it is used (640 px batch 16: 2.8 GB in 0.3 → 1.8 GB).
  • low_memory= for model.train: recompute activations instead of keeping them (identical gradients and BatchNorm statistics, ~30% slower, ~40% less memory). On CPU it is chosen automatically when needed, and a run that cannot fit stops before it starts, with the batch size that fits.
  • Crash protection: autosave of last.nbm every 10 minutes inside an epoch (autosave=), exact resume at the saved step (reproducible shuffling), Ctrl+C and SIGTERM stop at the end of the step, other errors save first, checkpoints are flushed to disk before replacing the old file.

0.3.11

  • Webcam window: thicker boxes and bigger labels on solid colour tags (both scale with the picture), FPS in the bottom-left, the window is just called "Workflow".

0.3.10

  • wf.inference("webcam", model) and workflow predict model.nbm webcam: live detection in a window, FPS on the picture. ← → (or ↑ ↓) and 0–9 switch camera; the controls and the current camera are shown in the console. record=True / --record saves the session, mirror=True / --mirror flips it.

0.3.9

  • library.md has an Example column (a ready-to-copy line per layer, block and tool) and full examples: a whole model, Residual, parallel, features, train → save → inference.

0.3.8

  • workflow init also writes library.md: every layer, block and tool in one table (also in the docs as Library).

0.3.7

  • Apple GPU (mps) training about 2.7× faster (the init model at 640: 16 → 45 images/s on an M2), same results.
  • The next batch is prepared while the current one trains (all devices).
  • Training shows validation loss, and a per-epoch table (0.3.6).

New

  • Own compute engine: native C CPU core, own CUDA kernels, experimental Apple GPU (MLX).
  • Layers: DepthwiseConv2D, PointwiseConv2D, SeparableConv2D, TransposeConv2D, DilatedConv2D; explicit numeric and asymmetric padding.
  • Blocks: SPP, SE, CBAM, Focus; Bottleneck is now a real reduce / spatial / expand bottleneck.
  • Composition: wf.parallel, wf.feature, wf.PAN over pyramids.
  • Quantisation: wf.QAT, post-training quantisation, workflow quantize, INT8 / FP16 .nbm and ONNX.
  • Errors with what / why / fix everywhere.
