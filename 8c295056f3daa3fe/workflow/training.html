Training

import felix as fx
import workflow as wf

dataset = fx.load("./dataset.felix")           # or a folder; model.train also accepts the path directly
model.train(dataset, epochs=100, batch_size=16, save_every=5)

Training uses Felix datasets; Workflow has no loader of its own. A Felix dataset provides dataset.train, dataset.val and dataset.test: datasets converted from COCO keep their split, generated ones are split deterministically 80/10/10 (Felix formats). Training uses the train split and validates on the val split every epoch.

Returns the training history: one dict per epoch with epoch, loss, box, obj, cls, lr, seconds, map50, map50_95, precision, recall, f1 and fitness. It is also kept in model.history.

model.train(False) and model.train() keep their usual torch meaning (eval() / train mode).

Defaults and what they do

  • Optimizer AdamW, weight decay 5e-4 on weights only (not BatchNorm / biases).
  • Schedule linear warm-up (about 3 epochs, at least 100 steps) then cosine decay to 1% of lr.
  • Gradient clipping at norm 10; training stops with a clear error if the loss becomes NaN.
  • Best model is chosen by validation fitness 0.1 × mAP50 + 0.9 × mAP50-95 (by training loss if there is no validation split).
  • Speed: mixed precision on CUDA, cuDNN autotuning, pinned memory and worker processes where supported.

Saved files

Written to save_dir as .nbm: last.nbm after every epoch, best.nbm on every new best, and epoch_N.nbm every save_every epochs. Each holds the weights (EMA), architecture, class names, history, optimizer state and the raw weights needed to continue exactly. See .nbm format.

Safe interruption

Press Ctrl+C at any time: training stops, the current state is saved to save_dir/last.nbm, and model.train returns normally with the history so far. The epoch counter in the file is the last *completed* epoch.

Continuing

model = wf.load("runs/train/last.nbm")        # or model.load(...) into an identical architecture
model.train(dataset, epochs=150, batch_size=16)

epochs is the total target: a run that stopped at epoch 80 continues from epoch 81 to 150. The optimizer state, raw weights, EMA and history are restored. If a file has no optimizer state, or it doesn't fit, a fresh optimizer is created. The learning-rate schedule is a function of progress towards the new target, so it stretches to the new epochs rather than restarting. If the model already reached the target, nothing runs.
