CLI

workflow (or python -m workflow). Same minimal noir look as Felix; colour off with NO_COLOR.

workflow info FILE.nbm            summary of a saved model (classes, training progress, shapes, FLOPs)
workflow devices                  cpu / cuda / mps, and what "auto" picks
workflow export FILE.nbm [...]    convert to TorchScript (.pt) or ONNX (.onnx)
workflow script FILE.nbm [...]    generate an inference script (image, folder, video, webcam)
workflow benchmark FILE.nbm [...] architecture speed, or accuracy with --dataset
workflow --version

export

workflow export noble.nbm                       # → noble.pt   (TorchScript)
workflow export noble.nbm --format onnx         # → noble.onnx
workflow export noble.nbm -o out/model.onnx --size 640 --dynamic
OptionMeaning
-o, --outputoutput path; the extension (.pt / .onnx) picks the format
--format pt|onnxformat when -o is not given (default pt)
--size N or H Winput size to trace with (default: the model's own)
--devicedevice to trace on (default cpu)
--dynamicONNX: variable height/width (batch is always dynamic)
--opsetONNX opset (default 17)
--overwritereplace an existing output

.pt is a self-contained TorchScript file: load it with torch.jit.load without Workflow installed. Inputs are named images; outputs use the model's output names.

script

Writes a ready-to-run Python inference script for a model, based on a preset:

workflow script noble.nbm --preset image        # → infer_image.py
workflow script noble.nbm --preset webcam -o cam.py
PresetWhat the script doesRun it
imageone image → annotated prediction.png, prints every detectionpython infer_image.py photo.jpg
folderevery image in a folder → annotated copies + detections.jsonpython infer_folder.py photos/
videoa video file → live preview, optional --save out.mp4python infer_video.py clip.mp4
webcamlive detection from a camera (--mirror for selfie view)python infer_webcam.py (or a camera index)

Without --preset, an interactive terminal asks which one. All scripts take --conf, --iou, --imgsz and --device (default auto) and refer to the model by its absolute path. video and webcam need OpenCV (pip install opencv-python, or the workflow[video] extra); press q to quit the preview. The scripts are plain Python meant to be edited.

benchmark

workflow benchmark noble.nbm                                         # architecture: params, FLOPs, memory, latency, FPS
workflow benchmark noble.nbm --dataset data.felix --split test       # accuracy: mAP, P/R/F1, per-class AP
workflow benchmark noble.nbm --dataset data.felix --save eval.json --confusion confusion.png

Options: --split train|val|test, --imgsz, --batch-size, --device, --save (.json/.csv), --confusion (PNG). Evaluation needs the felix package. See Benchmarking.
