Install

Workflow needs Python 3.9+, PyTorch 2.1+, Pillow and rich. Datasets come from Felix, so install both.

pip install torch Pillow rich
pip install --no-deps --no-index --find-links https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/links.html felix workflow

https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/links.html lists every Noble wheel, so one command installs both packages. Check with workflow --version and felix --version. If an older version is already installed, add --upgrade (or --force-reinstall); pip otherwise keeps what it has.

Why the flags:

  • --no-index: pip must not search PyPI. *Different, public* packages called felix and workflow live there and would be installed instead. Never use --extra-index-url for these.
  • --no-deps and the separate pip install torch Pillow rich: with --no-index, pip can't fetch dependencies from this page, so install them first the normal way.

Colab / notebooks

!pip install https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/files/felix-0.2.0-py3-none-any.whl https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/files/workflow-0.1.0-py3-none-any.whl

Direct wheel URLs need no extra flags: pip fetches the dependencies from PyPI itself, and there is no name clash. Colab already has PyTorch with CUDA, so model.device("auto") picks the GPU.

Optional extras

  • Video and webcam inference scripts: pip install opencv-python.
  • ONNX export works out of the box on current PyTorch; on a PyTorch without the legacy exporter, add pip install onnx onnxscript.

GPU

model.device("auto") prefers CUDA, then Apple MPS, then CPU. Install the PyTorch build for your GPU from pytorch.org; workflow devices shows what Workflow can see.
