Install

Workflow needs Python 3.9+, rich and Pillow. There is no PyTorch: the compute engine ships inside the package. Datasets come from Felix, so install both.

pip install rich Pillow numpy
pip install --no-deps --no-index --find-links https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/links.html felix workflow

Check with workflow --version and workflow devices. If an older version is installed, add --upgrade.

Why the flags: --no-index keeps pip from installing the unrelated public packages also called felix and workflow; with it pip cannot fetch dependencies, so --no-deps plus the first line installs them.

Colab / notebooks

!pip install https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/files/felix-0.4.1-py3-none-any.whl https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/files/workflow-0.3.1-py3-none-any.whl

Direct wheel URLs need no flags; pip fetches the dependencies from PyPI. Colab GPUs work with device="cuda".

The prebuilt Linux libraries need glibc 2.34 or newer (Debian 12+, Ubuntu 22.04+). On anything else Workflow compiles its C core once, into ~/.cache/workflow, the first time it is imported.

GPUs

  • NVIDIA: only the NVIDIA driver is needed (nvidia-smi must work). Workflow ships its own CUDA kernels as PTX; no CUDA toolkit, cuDNN or PyTorch is required.
  • Apple: pip install mlx enables device="mps". It is marked experimental and prints a warning when used.

Optional extras

  • pip install opencv-python for the video and webcam inference scripts.
  • Felix reads JPEG datasets through Pillow (installed above).
