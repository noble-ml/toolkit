Detection

Workflow's first task is bounding-box object detection: boxes, classes and confidences. (Segmentation, pose and classification are not part of this version.)

The head: BBoxHead

wf.Stage("head", wf.BBoxHead(inputs=("m3", "m4", "m5"), classes=3, outputs=("d3", "d4", "d5")))

The head is anchor-free. For every input level it applies two 3×3 Conv-BN-SiLU layers and a 1×1 conv. Each level produces one raw map of shape (N, 4 + 1 + classes, H, W):

ChannelsMeaning
0-3distances left, top, right, bottom from the cell centre to the box edges, in units of the level's stride (softplus is applied when decoding, so they are positive)
4confidence (objectness) logit
5…one logit per class

model(x) returns these raw maps as a dict keyed by the names in outputs. The head's design decisions:

  • Each level's stride is derived from the image and map sizes at decode time, so any input size that the architecture accepts works; nothing is hard-coded to 640.
  • classes is explicit in the architecture; training checks it against the dataset and explains a mismatch.
  • outputs is explicit, like every multi-output operation: one name per input level.
  • Levels can be fed in any order; their order is the order of inputs.

Decoding and NMS (inference only)

NMS is post-processing, not a network block. model.predict does, per image:

  1. Decode every cell to a box: centre ± (softplus distances × stride).
  2. Score = sigmoid(confidence) × sigmoid(class logit); each cell keeps its best class.
  3. Drop scores ≤ conf; keep the best 1000.
  4. Class-aware NMS: boxes of different classes never suppress each other; overlaps above iou are removed.
  5. Keep at most max_det and map the boxes back to the original image (undoing the letterbox).

model.predict

results = model.predict("test.png")            # also: PIL image, RGB numpy array, torch tensor, or a list of them
results = model.predict(photo, conf=0.25, iou=0.45, imgsz=640, max_det=300)

results.show()                                  # open the annotated image
results.save("prediction.png")                  # .png / .jpg
print(results.xyxy)                             # (N, 4) pixel boxes x1, y1, x2, y2 in the original image
print(results.classes)                          # ['square', 'circle', ...]
print(results.confidences)                      # (N,) scores

Images are letterboxed (resized keeping the aspect ratio, padded grey), so any image size works. A list input is processed in batches of 16 and returns a list of results. An RGB array is expected: OpenCV frames are BGR, so convert them with cv2.cvtColor(frame, cv2.COLOR_BGR2RGB).

Class names come from the dataset used for training and are stored in the .nbm.

Training targets and loss (what train optimises)

  • Assignment (FCOS-style, by object size): a pyramid level handles objects up to 8 × its stride (and above the previous level's range), so small objects train the fine maps and large objects the coarse ones. Cells inside the box and within 1.5 strides of its centre are positives; every object always gets at least its centre cell; where objects overlap the smaller one wins.
  • Loss = 5 × (1 − GIoU) on positive cells + BCE confidence (positives 1, all other cells 0) + BCE class, normalised by the number of positives.
