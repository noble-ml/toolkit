Blocks

Blocks are operations built from layers. They go anywhere a layer goes.

Implemented

Residual

wf.Residual(*ops, shortcut=None)

output = branch(x) + shortcut(x), where x is the block's own input (never an earlier stage).

ParameterRequirement
*opsone or more layers/blocks forming the branch (no operations that use named inputs/outputs)
shortcutoptional op or list of ops (e.g. wf.Conv2D(c_in, c_out, 1, stride=2)) to project the input. Default: identity

The branch output and the shortcut must have the same shape, or construction fails with the two shapes and how to fix it. Output = that shape.

Bottleneck

wf.Bottleneck(channels, expansion=0.5, shortcut=True)

1×1 Conv-BN-SiLU down to channels × expansion, then 3×3 Conv-BN-SiLU back up, added to the input.

ParameterRequirement
channelsint ≥ 1; must equal the input's channels
expansion0 < value ≤ 1 (hidden width = channels × expansion, at least 1)
shortcutbool; False returns the branch only

Returns one tensor with the input's shape.

CSP

wf.CSP(channels, out_channels=None, n=1, expansion=0.5, shortcut=True)

Cross-stage-partial block: a 1×1 conv splits the input into two paths; one runs n Bottlenecks; the paths are concatenated and fused by a 1×1 conv.

ParameterRequirement
channelsint ≥ 1; must equal the input's channels
out_channelsint ≥ 1; default channels
nint ≥ 1, number of Bottlenecks
expansion0 < value ≤ 1; hidden width = out_channels × expansion
shortcutbool, residual connection inside the Bottlenecks

Output: (out_channels, H, W).

SPPF

wf.SPPF(channels, out_channels=None, kernel_size=5)

Fast spatial pyramid pooling: 1×1 conv to channels // 2, three chained max-pools (stride 1) concatenated with the input, 1×1 conv to out_channels.

ParameterRequirement
channelsint ≥ 1; must equal the input's channels
out_channelsint ≥ 1; default channels
kernel_sizeodd int ≥ 3

Output: (out_channels, H, W).

Routing blocks

These read named tensors (inputs=), so they sit directly in a Stage (not inside Residual/CSP). See Routing.

Add

wf.Add(inputs=("a", "b", ...))

Elementwise sum. At least 2 distinct names; all inputs must have identical shapes. Output: that shape.

Concat

wf.Concat(inputs=("a", "b", ...))

Concatenates along channels. At least 2 distinct names; heights and widths must match, channels may differ. Output: (sum of channels, H, W).

FPN

wf.FPN(inputs=("p3", "p4", "p5"), channels=128, outputs=("n3", "n4", "n5"))

Top-down feature pyramid. Each input gets a 1×1 Conv-BN-SiLU to channels; starting at the coarsest level, the merged map is upsampled (nearest) and added to the next finer level; each level then gets a 3×3 Conv-BN-SiLU.

ParameterRequirement
inputs≥ 2 distinct names, ordered largest feature map first; each smaller than the one before
channelsint ≥ 1 (all outputs have this many channels)
outputsrequired: one distinct name per input, same order. There is no default naming

Input channels may all differ; weights are created from the inferred channels when the Model is built. Outputs keep their input's resolution. Must be the last operation of its stage.

PAN

wf.PAN(inputs=("n3", "n4", "n5"), channels=128, outputs=("m3", "m4", "m5"))

Bottom-up path aggregation, meant for FPN outputs. Inputs with a different channel count are projected with a 1×1 Conv-BN-SiLU. From the finest level, each level is downsampled with a stride-2 3×3 Conv-BN-SiLU, added to the next level, and refined with a 3×3 Conv-BN-SiLU.

ParameterRequirement
inputs≥ 2 distinct names, largest first; each exactly half the previous size, rounded up
channelsint ≥ 1
outputsrequired, one name per input

A mismatch (e.g. 80×80 followed by 20×20) fails when the model is built, naming both inputs.

Detection head

BBoxHead

wf.BBoxHead(inputs=("m3", "m4", "m5"), classes=3, outputs=("d3", "d4", "d5"), channels=None)

Anchor-free bounding-box head. It must be the last operation of the last stage for train, predict and benchmark(dataset) to find it. Design and tensor format: Detection.

ParameterRequirement
inputs≥ 1 distinct names of feature maps (usually PAN or FPN outputs), any order
classesint ≥ 1, part of the architecture; must equal the dataset's class count when training
outputsrequired, one distinct name per input
channelsoptional int ≥ 1: width of the head's convs (default: each input level's own channels)

Output: per level a raw map (4 + 1 + classes, H, W).
