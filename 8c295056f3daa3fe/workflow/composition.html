Composition

FunctionMeaning
wf.stack(wf.input(*None), *layers)layers in order. The outermost stack is the model; input is (C, H, W), default (3, 640, 640)
wf.Residual(*layers, shortcut="auto")layers(x) + shortcut(x). "auto": the input itself when the shape is kept, else a 1×1 Conv2D + BatchNorm2D that matches it. "identity": always the input (error if shapes differ). A layer or wf.stack(...): your own shortcut. False: no shortcut

Features

Features are how later layers reach back to earlier tensors. They are looked up by name only; Workflow never picks a tensor by position or channel count. A missing name lists the names that exist (with a "did you mean" when one is close), and a duplicate name is an error.

model = wf.stack(
    wf.input(channels=3, height=256, width=256),

    wf.Conv2D(32, kernel_size=3, stride=2, padding="same"),
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.feature("p3"),                  # 1/2 size, 32 channels

    wf.Conv2D(64, kernel_size=3, stride=2, padding="same"),
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.feature("p4"),                  # 1/4 size, 64 channels

    wf.PointwiseConv2D(32),
    wf.Upsample(scale=2),
    wf.feature("up"),                  # back to 1/2 size

    wf.concat("p3", "up"),             # 32 + 32 = 64 channels at 1/2 size
)

FPN and PAN

wf.FPN reads the named maps, orders them from the largest to the smallest, projects each to channels with a 1×1 Conv-BN-SiLU, adds every coarser map (resized, nearest) into the next finer one, and refines each level with a 3×3 Conv-BN-SiLU. Different sizes and channel counts are handled for you. channels defaults to the smallest input channel count.

wf.PAN then goes back up: the finest map is reduced by a stride-2 3×3 Conv-BN-SiLU, resized if needed, added to the next map, and refined.

Both return a pyramid: the next layer must accept several maps (wf.PAN, wf.head, or wf.feature((...)) to name them). A single-tensor layer after a pyramid raises an error that says so.

Residual shapes

With the default shortcut="auto", a wf.Residual whose layers change the shape gets a projection by itself: a 1×1 Conv2D with the stride and channels that match, followed by BatchNorm2D (the standard ResNet shortcut). When the layers keep the shape, the input is added directly and nothing is added to the model.

shortcut=What carries the input
"auto" (default)the input, or a 1×1 Conv2D + BatchNorm2D when channels or size change
"identity"always the input; an error if the shapes differ
wf.Conv2D(...)your own projection
wf.stack(...)your own shortcut network (e.g. wf.AvgPool2D(2, stride=2) then wf.Conv2D(128, 1))
Falsenothing: the block is just its layers

Auto cannot grow the picture or trim the border that padding="valid" removes; then it says so:

layer 2 (Residual): Residual cannot match its shortcut automatically.
  why: the layers turn (8, 6, 6) into (8, 4, 4); a 1×1 convolution can change channels and shrink by a stride,
       but not grow the picture or trim the border that padding='valid' removes.
  fix: use padding='same' inside the block, or give your own shortcut=wf.stack(...).
