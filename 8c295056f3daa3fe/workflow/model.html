Model

The outermost wf.stack(...) is the model.

MemberWhat it does
model.summary(input=None) (input=(3, 416, 416) checks another size)table of every layer's output shape, parameters and MACs; totals for parameters (trainable / non-trainable), size and GFLOPs. Returns the totals
model.output_shapethe output shape (a list of shapes for a pyramid / head)
model.check(input)output shape for another input size, or a ShapeError
model.count_parameters()(trainable, non_trainable)
model.plot() / model.export_graph("arch.png")draw the computation graph (PNG or SVG; detail="compact" for one row per layer)
model.device("cuda") / model.device()move the model / current device (Devices)
model.train(...)Training
model.predict(...)Detection
model.save(path), model.load(path), wf.load(path).nbm files (below)
model.export(format=..., output=..., precision=...), model.quantize(...)Quantisation and export
model(x, train=False)forward pass on a (N, C, H, W) Workflow tensor
model.history, model.class_names, model.precisiontraining history, class names (from the dataset), fp32 / fp16 / int8
model.set_classes(names)re-targets the head at other classes: its last prediction layer starts afresh, every other weight is kept (what wf.fine_tune does when the classes differ)
model.labels(), wf.labels("model.nbm")what the model detects (or classifies): its class names in class-id order ("0", "1", … before training on named classes); the file form reads only metadata

FLOPs count convolutions (2 per multiply-accumulate); BatchNorm folds into the convolution at inference and activations, pooling and additions are negligible.

The graph

model.export_graph("architecture.png") draws one row per layer with arrows, blocks with their real branches (residual shortcuts, CSP and SPP splits, attention gates with a × merge) and named features as red edges from wf.feature to the layers that read them. It needs Pillow for PNG; SVG needs nothing.

.nbm files

.nbm (Noble Model) is the only model format. It is a zip archive:

EntryContent
meta.jsonarchitecture, input shape, class names, detection settings, precision, quantisation ranges, training progress, and an index of every tensor
weights.binthe tensors: float32, float16, or int8 with a scale per tensor
train.binafter training: optimizer moments and the raw (non-EMA) weights, for exact continuation

wf.load(path) rebuilds the architecture from the file; model.load(path) fills an identical architecture. Saving is atomic (written to .part, then renamed). Files from Workflow 0.1 (the PyTorch version) cannot be read: the error says so.
