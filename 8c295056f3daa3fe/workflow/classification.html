Classification

A classification model gives one label per picture ("cat"), instead of boxes. It is the same wf.stack you already write, ending in wf.head(..., type="cls"), trained on a folder of class folders.

The data: class folders

The usual ImageNet layout, one folder per class with its pictures inside. fx.load reads it as it is: nothing is copied or written next to the images.

animals/                      animals/
├── cat/                      ├── train/
│   ├── 001.jpg               │   ├── cat/ …
│   └── …                     │   └── dog/ …
├── dog/                      ├── val/
└── bird/                     │   ├── cat/ …
                              │   └── dog/ …
                              └── test/ …
  • Class folders only (left): every class is split 80 / 10 / 10 into train / val / test *on its own*, so each split has every class in the same proportion. The split is fixed (seed 0): the same folder always gives the same splits.
  • train/ val/ test/ folders (right; valid, validation, training, testing work too): those splits are used.
  • Class names are the folder names, in natural order (class2 before class10); class ids follow that order.
  • Images can be PNG, JPEG, BMP, WebP, GIF or TIFF, any size, nested any depth inside a class folder. Hidden files and folders (starting with . or _) are skipped.
import felix as fx

data = fx.load("animals/")
data.task        # "classification"
data.classes     # ['bird', 'cat', 'dog']
data.splits      # {'train': 2400, 'val': 300, 'test': 300}

Everything else in Felix works on it: felix info animals/ (images per class and split), felix pack animals/ -o animals.felix (one file), felix split animals/ 0.1 (a tenth, keeping every class's share in every split), felix partition.

The head

wf.head(classes=3, channels=None, type="cls")
ArgumentMeaning
classeshow many classes (must match the dataset; training checks)
channelsNone: pool the last feature map as it is. A number: first widen it with a 1×1 Conv-BN-SiLU to that many channels (e.g. 1024 or 1280, as large classifiers do)
type"cls" (or "classify") for classification; "bbox" (the default) for detection

Inside: (optional 1×1 Conv-BN-SiLU) → global average pooling → a fully connected layer (a 1×1 convolution) with one logit per class. The output is (classes, 1, 1). After a pyramid (FPN / PAN) it uses the last, deepest map. The class biases start at zero, so every class starts equally likely.

A model

import felix as fx
import workflow as wf

data = fx.load("animals/")

model = wf.stack(
    wf.input(channels=3, height=224, width=224),

    wf.Conv2D(32, kernel_size=3, stride=2, padding="same"),     # 224 → 112
    wf.BatchNorm2D(),
    wf.SiLU(),

    wf.Conv2D(64, kernel_size=3, stride=2, padding="same"),     # 112 → 56
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.CSP(out_channels=64, n=1),

    wf.Conv2D(128, kernel_size=3, stride=2, padding="same"),    # 56 → 28
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.CSP(out_channels=128, n=2),

    wf.Conv2D(256, kernel_size=3, stride=2, padding="same"),    # 28 → 14
    wf.BatchNorm2D(),
    wf.SiLU(),
    wf.CSP(out_channels=256, n=2),

    wf.head(classes=len(data.classes), channels=512, type="cls"),
)

model.train(data, epochs=50, batch_size=32)

ResNet-style networks are a few lines too: wf.Residual(...) with the default shortcut="auto" adds the 1×1 projection wherever a block changes channels or size.

Training

model.train is the same call as for detection; with a classification head it:

  • uses softmax cross-entropy with label smoothing 0.1 (the target is 90% the right class, 10% spread over all);
  • augments with a random crop (25–100% of the area, aspect 3:4 to 4:3), a horizontal flip and brightness / contrast jitter; validation and testing use the whole picture;
  • reports the training loss, the validation loss and top-1 / top-5 accuracy each epoch, and keeps best.nbm by 0.9 · top-1 + 0.1 · top-5;
  • keeps everything else: AdamW, warm-up + cosine schedule, EMA weights, early stopping, autosave, exact resume, low_memory, every device.
epoch   train loss   val loss   top-1   top-5
    1        1.055      0.931   0.470   1.000
    2        0.771      0.702   0.830   1.000  ← best

A classification model refuses a dataset with boxes (and a detector refuses class folders), saying which head to use.

Evaluation

result = wf.eval(model, dataset=data.test)
result.top1, result.top5      # accuracy
result.per_class              # [{"class": "cat", "images": 300, "accuracy": 0.93}, ...]
result.confusion_matrix       # rows: true class, columns: predicted class

show() prints the size / speed table, top-1, top-5, the cross-entropy and the accuracy of every class.

Predicting

r = model.predict("photo.jpg")
r.class_name, r.confidence    # "cat", 0.93
r.top                         # the five best: [{"class": "cat", "class_id": 1, "confidence": 0.93}, ...]
r.probabilities               # one per class, summing to 1
r.save("labelled.png")        # the picture with its label (and the runners-up) in the top-left corner

wf.inference(source, model, output) and workflow predict work as for detection, on images, folders, videos, datasets and the webcam: annotated pictures get the label tag, and predictions.json holds class, class_id, confidence and top for each image.

Export

model.export("onnx") writes the logits ((N, classes, 1, 1)); apply a softmax to get probabilities. The .nbm file records the task ("classify"), so wf.load gives back a classifier.
