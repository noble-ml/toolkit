Errors

Every Workflow error has three parts and names where it happened:

layer 3 (Concat): wf.concat refers to the feature 'b', which does not exist here.
  why: features must be registered with wf.feature(...) earlier in the model; registered so far: a.
  fix: add wf.feature("b") after the layer whose output you want.
ClassRaised for
wf.ShapeErrora layer receives a shape it can't use (wrong channels, kernel larger than the input, residual paths that differ, a pyramid where one map is expected)
wf.RoutingErrormissing, duplicate or mislabelled features
wf.DeviceErrora device that isn't available
wf.BackendErrorthe native core or a GPU backend can't load or run something (with the driver's reason)
wf.DataErrorunreadable images, empty splits, class-count mismatches
wf.SerializationErrorinvalid model files, architecture mismatches, unsupported export formats
wf.WorkflowErrorthe base class of all of the above (also invalid arguments)

Non-fatal issues are wf.WorkflowWarning warnings: the experimental Apple GPU, quantising without calibration data, layers that stay float in an int8 model.

Errors carry what, why, fix and where attributes for programs that want them.
