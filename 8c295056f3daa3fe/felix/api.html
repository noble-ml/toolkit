API reference

import felix as fx. The calls build a dataset step by step; fx.export runs them in the order they were made.

fx.load_class(path) → list of class names

Load the target classes from YAML:

classes:
  - leaf                                # just a name
  - name: fruit
    prompt: a ripe tomato on the vine   # for open-vocabulary models (default: the name)
  - name: dog
    prompt: [dog, puppy, a dog lying down]   # several prompts: any of them finds the class
    aliases: [tomato, Tomato]           # names that mean this class in imported data / model labels
    confidence: 0.4                     # optional minimum model confidence for this class
confidence: 0.25                        # optional default

Several prompts (prompt: [...], or prompts:) all look for the same class: YOLOE is asked for each, the boxes are named after the class, and boxes of one class overlapping by more than 60 % (two prompts finding the same object) are merged, keeping the most confident. A prompt may belong to one class only. Use it for synonyms ("car", "automobile"), kinds ("sedan", "hatchback") and looks ("a dog lying down").

A bare list (classes: [leaf, fruit] or a top-level list) works too. Class ids follow the file's order. Imported boxes and detections are mapped onto these names (case-insensitive, through aliases); others are left out. Without a class file, every class is kept and models detect all they know.

fx.acquire(sources, blur_faces=False)

Add sources (a list of fx.sources; call again to add more). Nothing downloads yet. blur_faces=True puts fx.transform.blur_faces() first, so every image is blurred before any other step.

fx.transform

Each call adds a step. Boxes and segmentation polygons move with the pixels; boxes keeping less than min_visibility of their area after a crop are dropped.

consequential. For each object not already well covered by a crop, a square around it with margin of its size on each side, at least size pixels where the image allows (small objects are not blown up), kept inside the image (grey padding only for objects larger than the short side). Every object inside a crop keeps its box. A crop overlapping an earlier crop of the same image by more than overlap (IoU) is skipped. Negatives (squares touching no object, from the same images or from annotated images without objects) are added so they make up negative_rate of the output. Images whose annotation failed are left out, never used as negatives. Calling it before fx.annotate, or a geometry step after it, raises an error at once.

augment. Each image gets copies new versions; the original stays unless keep_original=False.

  • Geometry (boxes and masks move with the pixels): flip / vflip are probabilities, rotate is ± degrees, scale and translate are ± fractions (scale=0.2: 80–120 %). Uncovered corners are grey. Boxes keeping less than min_visibility of their area are dropped.
  • Colour: brightness, contrast, saturation (± fractions), hue (± degrees).
  • Damage: blur, grayscale, jpeg (probabilities of a slight blur, no colour, heavy compression), noise (largest noise as a fraction of the brightness range), cutout (probability of a grey patch; boxes more than 60 % hidden are dropped).
  • Set an option to 0 to turn it off. With rotate, scale and translate at 0 (flips and colour are fine) it may come after consequential.
  • Augment *after* fx.annotate, so the model labels the real pictures and the copies inherit those labels.

mosaic. rate mosaics per input image (0.25: one per four). Each mosaic puts four whole images, each fitted into a quarter, in one size picture. It lists its four parts as its source, so attribution and licence checks cover all of them.

Splits stay clean. Augmented copies, mosaics and consequential crops always land in the same train / val / test split as the image they came from, so no version of a test image is ever trained on.

fx.annotate(model, confidence=None, replace=False, batch_size=8)

Boxes for every image without labels. model:

  • a Workflow model: wf.load("custom.nbm") (detection gives boxes; a classification model gives image labels);
  • a built-in model: fx.models.yolo26n (also yolo26s/m/l/x, yolo26n_seg), fx.models.yoloe (open vocabulary: prompted with classes.yml's prompts; without a class file, its prompt-free version), fx.models.sam (adds masks to existing boxes); call one to choose other weights, e.g. fx.models.yolo26n("yolo26s.pt");
  • a function fn(image) -> [{"class", "bbox": [x, y, w, h] or "xyxy": [x1, y1, x2, y2], "confidence"}].

confidence: the minimum score; by default 0.25, and 0.1 for fx.models.yoloe when it is prompted by a class file (open-vocabulary scores run lower: a "shoe" prompt scores ~0.16 where a closed-set "person" scores ~0.9). classes.yml can set it per class.

Built-in models run through Ultralytics (pip install ultralytics). Bundled inside Felix, so they work offline: yolo26n.pt, yoloe-26s-seg.pt (text prompts) and yoloe-11s-seg-pf.pt (prompt-free: YOLOE-26's own prompt-free weights give nonsense under current Ultralytics). Other weights (fx.models.yolo26s, fx.models.sam, or fx.models.yoloe("yoloe-26l-seg.pt")) are downloaded once into ~/.cache/felix/models. YOLOE's prompts come from classes.yml (prompt:, else the class name) and its detections are named after your classes; the first prompt downloads Ultralytics' text encoder (~254 MB) into the same cache. With several prompts, one class's boxes never suppress another's. Prompts work best for whole objects ("shoe", "jacket", "bus"); parts ("tyre", "bus window") are often missed even by the larger YOLOE. device= picks where a built-in model runs: fx.models.yoloe(device="cpu"). Ultralytics models are AGPL-3.0 (or an Ultralytics Enterprise licence).

replace=True also re-annotates images that came with labels (otherwise model boxes are added only to unlabelled images). Each box records its confidence and origin; each image records the model. An image the model fails on is marked failed, reported, and left out of the export.

fx.export(path, pairs=None, *, license=None, title=None, authors=None, description=None, version=None, strict=False, shard_size=1000, overwrite=False, quiet=False, use="commercial") → summary dict

Runs everything and writes the dataset:

  • path: name.felix (one file), a folder, or name.sh_felix (the folder name/ of shards, shard_size pairs each);
  • pairs: stop after this many image/annotation pairs; None = until the sources run out, or Ctrl+C / kill, after which the dataset written so far is closed properly;
  • license: None (closed: all rights reserved for the compilation), an open licence id ("CC-BY-4.0", "CC-BY-SA-4.0", "CC0-1.0", "CC-BY-NC-4.0", "ODbL-1.0", …) or "auto" (the most permissive one every image allows); strict=True leaves out images whose licence does not fit; see Licences;
  • title, authors, description, version: for LICENSE.txt and CITATION.cff;
  • use: what the dataset is for, which decides the image licences taken at all (the rest is skipped before it is downloaded and counted in a note): "commercial" (default, the safest: fits a closed-source commercial product, so public domain / CC0, CC BY, Pexels / Pixabay / Unsplash licences and your own files), "open" (also share-alike), "research" (also non-commercial), "any" (everything; licences still recorded). See Licences.

Images without a split get a stable 80 / 10 / 10 train / val / test split from their name; imported splits are kept. Returns {"pairs", "path", "license", "splits", "licence_issues", "use", "licence_skipped", "failed", "stopped", "sources"}.

fx.reset()

Forget the class file, sources and steps (start another dataset in the same program).

Reading and managing datasets

  • fx.load(path) → Dataset: a .felix file, a folder, a folder of shards, a single .sh_felix, or class folders. len(ds), ds.stems, ds.classes, ds.metadata, ds.task, ds.splits, ds.train / ds.val / ds.test, ds.annotation(stem), ds.image(stem) (a Pillow image), ds.image_bytes(stem); shards also ds.shards, ds.shard_of, ds.load_shard(i) / ds.release_shard(i).
  • fx.split(source, fraction=None, output=None, *, size=None, seed=0): a smaller copy (same share of every split and class).
  • fx.partition(source, output=None, parts=None, ratio=None, size=None, by_split=False, …): several smaller datasets.
  • fx.shard(source, output=None, *, size=None, shards=None): a folder of .sh_felix shards.

Errors

Every problem raises fx.FelixError with a message saying what to change.
