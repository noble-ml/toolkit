API reference

import felix as fx

Classes

fx.class_set(name)

Context manager. Shapes created inside become classes of the set name. Re-using a name adds to the same set. Class names must be unique across the whole project.

fx.toolkit shapes

All return a shape; all accept position=(x, y) (default placement), name= (override the inferred class name) and, except image, color= (hex, CSS name or RGB tuple).

Steps

fx.step(size=(640, 640), name=None)

Context manager; see Getting started. Several steps may be defined; make splits pairs evenly between them. Steps cannot be nested.

fx.canvas.background(color=None, image=None)

color is a colour (or random node). image is a file, or a folder (one image picked at random per sample); it is cover-fitted to the canvas. Default is white.

fx.paint(target, position=None) → handle

target can be a random class node, a class variable, a class name string, None (no-op), or a plain shape that is *not* a class (drawn but never annotated). position is the object's centre in pixels (value or random node). Default: the shape's position, else canvas centre.

fx.toolkit.transformation(handle, hue=None, brightness=None, rotation=None, scale=None, opacity=None)

  • hue: degrees added to the hue (-180..180 covers everything)
  • brightness: multiplier (1 = unchanged)
  • rotation: degrees, counter-clockwise (the sprite grows so nothing is clipped)
  • scale: multiplier, > 0
  • opacity: multiplier 0-1

Repeated calls accumulate (hue/rotation add; the rest multiply). Any parameter may be a random node. Ignored once fx.gen() has annotated the object.

fx.gen()

Annotate all not-yet-annotated objects painted so far. See Getting started.

Output

fx.make(pairs, output, seed=None, overwrite=False, quiet=False)

Writes pairs images + annotations. output ending in .felix writes a compiled file, otherwise a folder. Refuses to overwrite an existing dataset unless overwrite=True. Prints a live progress panel (disable with quiet=True). Returns {"pairs", "seed", "boxes", "output"}.

fx.load(path) → Dataset

Read a folder or .felix: len(ds), ds.metadata, ds.stems, ds.classes (names ordered by class id), ds.annotation(stem), ds.image(stem) (PIL image), ds.image_bytes(stem), iteration yields (stem, annotation). Use as a context manager or call ds.close(). Datasets are picklable (each DataLoader worker re-opens its own file handle).

Splits. ds.train, ds.val (alias ds.valid) and ds.test are lightweight Subset views with the same read API (len, stems, annotation, image, iteration, classes, metadata); ds.splits gives the counts.

  • If the annotations carry a split field (converted datasets), it is used (valid/validation count as val).
  • Otherwise the dataset is split deterministically 80/10/10: shuffled with the dataset's seed, so the same file always gives the same splits. Datasets with fewer than 10 pairs are not split (all train).

fx.reset()

Clear all classes and steps (tests, notebooks).

Errors

All user-facing problems raise fx.FelixError.
