Felix

A Python toolkit for building computer-vision datasets from real images: collect them from your files, videos, cameras and online collections, transform them, label them with a model, and export one clean dataset, with every image's source and licence recorded and the licence and citation files written for you.

import felix as fx
import workflow as wf

fx.load_class("./classes.yml")

fx.acquire([
    fx.sources.local("./raw/leaves"),
    fx.sources.urls("./leaf_urls.txt"),
    fx.sources.video("./greenhouse.mp4", sampling=fx.sampling.auto()),
    fx.sources.wikimedia(query="plant leaves", limit=1000),
])

fx.transform.center_crop(size=640)

model = wf.load("./models/leaf-detector.nbm")
fx.annotate(model=model)

fx.export("./datasets/leaf-center.felix")

No pipeline objects, no run(): each line adds a step, and fx.export runs them in order. Images stream through, so fx.export(..., pairs=5000) stops after 5,000 pairs; without pairs it keeps going until the sources run out or you stop it (Ctrl+C), and the dataset written so far is closed properly.

What is in it

  • Sources (fx.sources), 20 of them: your files (folders, single images, archives, existing COCO / YOLO / Felix datasets), video files, cameras and streams, web URLs, Wikimedia Commons, Openverse, Flickr, Unsplash, Pexels, iNaturalist, GBIF, NASA, the Art Institute of Chicago, the Smithsonian, Roboflow, Open Images, COCO 2017, Hugging Face, Kaggle and Mapillary. Each uses its provider's real API and keeps what the provider says about licence and attribution. Leave out the query and a search source takes whatever it has. Downloads run in parallel over kept-alive connections (10–20× faster than 1.1), and downloaded images are cached for fast re-runs.
  • Video sampling (fx.sampling): auto() (only when the scene changes), interval(seconds=), random(count=).
  • Transforms (fx.transform): center_crop, letterbox, consequential (object-focused crops plus negative samples), augment (flips, rotation, scale, shifts, colour, blur, noise, cutout, JPEG damage), mosaic, dedupe, map_classes, filter_classes, filter_images, blur_faces, and custom for your own. Boxes and masks move with the pixels; augmented copies, mosaics and crops stay in their original's train / val / test split.
  • Annotation (fx.annotate): with your own Workflow model, or the built-in fx.models.yolo26n, fx.models.yoloe (open vocabulary, prompted from classes.yml; both bundled, so they work offline) and fx.models.sam (masks for boxes). Images the model fails on are never mistaken for images without objects.
  • Export (fx.export): a .felix file, a folder, or a folder of .sh_felix shards, with LICENSE.txt, ATTRIBUTIONS.md and CITATION.cff, for an open (license="CC-BY-4.0" or "auto") or closed dataset.
  • Dataset files: fx.load (what Workflow trains from), fx.split, fx.partition, fx.shard, and the felix command (info, pack, convert, library, …).
