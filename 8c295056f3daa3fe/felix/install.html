Install

Anywhere (index)

pip install Pillow rich
pip install --no-deps --no-index --find-links https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/simple/felix/ felix

Works on Linux, macOS and Windows (Python 3.8+). Check with felix --version.

Why the extra flags:

  • --no-index: pip must not search PyPI. A *different, public* package called felix lives there and would be installed instead of this one. Never use --extra-index-url for Felix.
  • --no-deps and the separate pip install Pillow rich: with --no-index pip can't fetch dependencies from this page, so install them first the normal way.

Upgrade by adding --upgrade --no-cache-dir; pin a version with felix==1.2.0.

Colab / notebooks (direct link)

Credentials and contact

Online sources that need keys read them from the call, environment variables or ~/.config/felix/credentials.yml (see Sources). Set FELIX_CONTACT to an email or URL so providers can reach you, as Wikimedia's policy asks.

Caches

Large downloads (Open Images CSVs, COCO, Roboflow exports, model weights) are cached in ~/.cache/felix (FELIX_CACHE to move it). Working copies made during an export live in a temporary folder that is removed afterwards.
