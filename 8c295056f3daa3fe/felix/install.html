Install

Colab / notebooks (direct link)

!pip install https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/files/felix-0.2.0-py3-none-any.whl

A direct wheel URL needs no extra flags: pip fetches Pillow and rich from PyPI itself, and there is no name clash because it never searches an index for felix. Replace the version in the file name for other releases (all wheels stay on the site).

Anywhere else (index)

pip install Pillow rich
pip install --no-deps --no-index --find-links https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/simple/felix/ felix

That's it. Works the same on Linux, macOS and Windows (Python 3.8+). Check with felix --version.

Why the extra flags:

  • --no-index: pip must not search PyPI. A *different, public* package called felix lives there and would be installed instead of this one. Never use --extra-index-url for Felix.
  • --no-deps and the separate pip install Pillow rich: with --no-index pip can't fetch dependencies from this page, so install them first the normal way.

Upgrade to the newest version by adding --upgrade; pin one with felix==0.2.0.

Try the example pipeline: download animals.py and bicycle.png (keep it in an assets/ folder next to the script), then run python animals.py.
