CLI

felix (or python -m felix). Output is a minimal monochrome ("noir") panel built on rich, redrawn in place on a terminal (colour unless NO_COLOR is set); piped or on CI it prints just the final frame.

felix run SCRIPT [args...]            run a pipeline script
felix pack FOLDER [-o OUT.felix]      folder -> single compressed .felix
felix unpack FILE.felix [-o FOLDER]   .felix -> folder
felix info PATH                       summary + per-class box counts (folder or .felix)
felix convert coco SRC -o OUT         Roboflow/COCO -> Felix
felix --version

All writing commands refuse to overwrite existing output unless --overwrite is given.

Converting a Roboflow COCO export

Export from Roboflow in COCO format, then:

felix convert coco ./my-export       -o ./my-felix-dataset
felix convert coco ./my-export.zip   -o ./my-dataset.felix
  • SRC is the export folder or its .zip. Every _annotations.coco.json found (usually train/, valid/, test/) is converted; the split is stored per annotation (split: train).
  • Images are copied untouched as IMG<n>.<original ext> (fast, no size growth). Add --png to re-encode everything to PNG instead - note JPEG→PNG makes files roughly 8-10x larger.
  • Roboflow's placeholder parent category is dropped; each category's supercategory becomes its class set (default if none). Class ids are renumbered from 0.
  • Boxes stay xywh pixels. Missing image files are skipped and reported.
