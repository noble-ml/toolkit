Felix

A lightweight dataset pipeline generator for object detection. Describe classes and a generation step in a few lines of Python; Felix renders images, tight bounding boxes and metadata. Pure Python + Pillow + rich. Works on Linux, macOS and Windows (Python 3.8+).

import felix as fx

with fx.class_set("animals"):
    cat = fx.toolkit.circle(radius=30)
    dog = fx.toolkit.rectangle(width=50, height=40)

with fx.step(size=(640, 640)):
    fx.canvas.background("#eeeeee")
    obj = fx.paint(fx.random.class_(), position=fx.random.position(margin=40))
    fx.toolkit.transformation(obj, rotation=fx.random.uniform(0, 360))
    fx.gen()

fx.make(pairs=10_000, output="./dataset")        # folder
# fx.make(pairs=10_000, output="./dataset.felix")  # one compiled file

Try the full example: animals.py (python examples/animals.py or felix run examples/animals.py).

Install

See Install. Short version:

pip install Pillow rich
pip install --no-deps --no-index --find-links https://YOUR-USER.github.io/YOUR-REPO/8c295056f3daa3fe/simple/felix/ felix

(--no-index stops pip from fetching the unrelated public felix from PyPI.)
